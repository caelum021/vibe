# vibe (Web UI) — Lightweight AI IDE

**vibe**는 브라우저 기반의 초경량 AI IDE입니다. 로컬 터미널의 강력함과 브라우저의 우아한 UI를 결합하여, AI CLI(Claude Code, Gemini 등)를 가장 쾌적하게 사용할 수 있는 환경을 제공합니다.

## 🚀 시작하기

### 1. 설치 및 명령어 등록
클라이언트를 빌드하고 서버에서 명령어를 전역으로 등록합니다.
```bash
# 클라이언트 빌드
cd client
npm install
npm run build

# 서버 설정 및 명령어 등록
cd ../server
npm install
npm link
```

### 2. 실행
원하는 프로젝트 폴더로 이동하여 `vibe`를 입력하세요.
```bash
# 현재 폴더에서 시작
vibe .

# 특정 폴더에서 시작
vibe ~/projects/my-awesome-app
```

## ⌨️ 주요 단축키

| 기능 | 단축키 | 설명 |
|:---:|:---:|:---|
| **사이드바 토글** | `Ctrl + B` | 파일 탐색기를 숨기거나 나타냅니다. |
| **터미널 포커스** | `Ctrl + \`` | 어디서든 즉시 터미널로 입력 포커스를 옮깁니다. |
| **탐색기 이동** | `Esc` | 터미널/뷰어에서 빠져나와 파일 탐색기로 이동합니다. |
| **파일 열기** | `Enter` | 탐색기에서 파일을 선택하여 뷰어(중간 창)에 엽니다. |
| **뷰어 닫기** | `Esc` | 뷰어에 포커스가 있을 때 누르면 뷰어를 닫습니다. |

## ✨ 주요 특징
*   **완벽한 터미널**: 사용자의 기본 쉘($SHELL)과 100% 연동되며 256컬러를 지원합니다.
*   **지능형 레이아웃**: 파일을 열면 자동으로 3단으로 변하며, 닫으면 다시 터미널이 넓어집니다.
*   **보안**: 로컬 프로젝트 폴더 외부로의 파일 접근을 원천 차단합니다.
*   **자동 종료**: 모든 브라우저 탭을 닫으면 3초 후 서버가 자동으로 종료됩니다.
